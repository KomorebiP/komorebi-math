# Known issues after R4 Block 5

Block 5 closes only its recorded prerequisite-composition scope. Remaining release work includes:

- certificate mutation, caching, snapshot and stale-evidence lifecycle;
- serialization, loading, stored validity and revalidation;
- resource/allocation guards and malformed-input audit;
- optional CuPy/GPU execution paths, including device residual/tolerance behavior;
- integrated whole-library regression replay;
- advertised Windows/PowerShell/CUDA/dependency qualification;
- whole public documentation reconciliation and independent review.

A composed certificate records the prerequisites it actually checks. It does not turn global
derivative regularity, external theorems, analytic continuation or other unresolved premises
into proof. Finite sampled numerical tests remain finite sampled numerical evidence.
