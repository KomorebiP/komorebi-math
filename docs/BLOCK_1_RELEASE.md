# Block 1 release record

Version `0.1.0a1` establishes the executable finite dimensional foundation of Komorebi Math.

## Implemented execution stages

The unified language is

```text
seed -> address -> operate -> project -> transfer -> refine -> constrain -> complete -> reconstruct
```

This release implements the first five stages and finite packet reconstruction.

### Seed

`SeedSystem` computes finite orbit hulls, generation certificates, orbit layers, finite presentations, small finite seed searches, semisimple seed rank formulas, and exact single operator seed rank for rational matrices.

### Address

`OperatorGrammar` records typed spaces, arrows, composable words, identities, and finite linear path relations.

### Operate

`OperatorRealization` evaluates typed paths and verifies relations. `OperatorAlgebra` computes the unital matrix algebra generated by a finite family and verifies multiplicative closure.

### Project

`PacketSystem` validates finite complete idempotent families and implements analysis, synthesis, support, aggregation, tensor products, dual packets, coordinate transport, invariant subspace restriction, and invariant quotient descent.

### Transfer

`PacketOperator` resolves operators into source and target blocks. The package implements block reconstruction, composition, adjoints, tensor products, powers, path expansions, transfer graphs, strongly connected components, condensation, support preorders, and nilpotency bounds.

### Reconstruct

Finite packet vectors and packet operators reconstruct exactly under the exact backend and within a declared tolerance under the NumPy backend.

## Runtime infrastructure

The release also provides:

* exact, numerical, conditional, heuristic, and planned result classes

* a command line interface

## Backends

The base installation requires NumPy.

The optional SymPy backend preserves exact rational matrix arithmetic. SymPy is imported only when requested.

Later backends may implement the same `LinearAlgebraBackend` contract without changing the core public objects.

## Validation completed

The production suite contains 68 tests. The installed package self check contains six independent core checks. Wheel and source archive installations were tested outside the source tree. The exact SymPy path was tested separately with rational inputs.

The distribution audit verifies package metadata, module imports, source syntax, wheel contents, source archive contents, optional dependency isolation, and absence of paper or verification directory imports from production code.

Both distribution artifacts are reproducible when built with the same `SOURCE_DATE_EPOCH`.

## Boundaries

This alpha release does not yet implement the mathematics of Papers II through XII beyond interfaces that belong to the finite core. In particular, refinement towers, obstruction quotients, signals, semigroups, arithmetic coordinates, deformation forests, and Langlands finite models remain future blocks.

The package does not treat numerical checks as proofs. It does not present conditional constructions as unconditional objects. It does not load implementations from manuscript verification directories.
